# Website workflow

Inspect the existing framework, content, and run instructions. Implement the requested user flow, including validation, empty states, failure states, and accessible labels. Verify the real data or API boundary and identify mock data. Run the project's checks and start a local preview. If browser is available, inspect representative phone and desktop sizes and exercise the main flow. If browser or vision is unavailable, report visual review as open. Give an exact preview command and URL. A local preview or successful build does not prove deployment. Keep implementation details out of product-facing copy unless they help the user decide.
