# Harness direction

Harness is a personal coding tool under MIT. The immediate work is reliability and usability of the existing runtime, governed by [the ordered backlog](CTO_BACKLOG.md) and [the acceptance record](PERSONAL_USE.md).

Keep the core workflow short: configure an explicit route, work in a repository, review and execute tools, preserve the session, and recover from interruption. Keep local providers and compatible endpoints available. Improve error messages and recovery before increasing the feature surface.

Optional integrations remain opt-in. Add functionality when an actual personal task needs it; verify that task end to end. Marketing, competition, community growth, paid distribution, and broad platform packaging are outside this roadmap.
